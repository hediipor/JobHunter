# Running JobHunter AI

1. Double-click `JobHunterAI.exe`.
2. A browser window opens automatically — if it doesn't, go to http://127.0.0.1:8000
3. Follow the setup wizard: paste in your API keys (free, links provided in the wizard) and fill in your profile.
4. That's it — click "Scan Jobs Now" on the dashboard whenever you want fresh listings.

Your data (jobs, applications, your profile, your API keys) is stored in files next to JobHunterAI.exe — nothing is sent anywhere except the job-search APIs and Google Gemini you configure yourself.
